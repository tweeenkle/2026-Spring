# 🌸 ReflectAI (Pink Edition)

ReflectAI는 SEED 디자인 시스템(Pink 테마)을 적용하여 새롭게 단장한 모바일 친화적 웹 애플리케이션입니다. 사용자가 매일의 감정을 기록하고, 하루를 돌아보는 질문에 답하며 스스로의 마음을 돌볼 수 있도록 돕습니다. 이번 업데이트에서는 **Google 로그인 연동**, **모의 결제 시스템**, 그리고 **프리미엄 감정 분석 리포트** 기능이 새롭게 추가되었습니다.

---

## ✨ 주요 기능 (Key Features)

### 1. 🔑 사용자 인증 및 계정 관리 (Google Login & Profile)
*   **Google Identity Services 연동**: 구글 원탭 로그인 및 로그인 버튼을 통한 간편한 사용자 인증을 지원합니다. (커스텀 Client ID 입력 기능 지원)
*   **구글 로그인 시뮬레이터 (Google Login Simulator)**: 실제 구글 Client ID가 없어도 시뮬레이터를 사용하여 이름과 이메일을 가상으로 설정하고 로그인 흐름을 원활하게 테스트해볼 수 있습니다.
*   **헤더 프로필 영역**: 로그인 후 사용자의 구글 프로필 이미지(또는 기본 아바타)가 상단 헤더에 실시간 반영되며, 프로필 이미지를 클릭하면 상세 정보 조회, 로그아웃, 전체 데이터 초기화가 가능한 모달이 제공됩니다.

### 2. 💳 프리미엄 결제 시스템 (Mock Payment Gateway)
*   **평생 소장권 구매**: 프리미엄 리포트 기능을 영구적으로 활성화할 수 있는 'ReflectAI 프리미엄 평생 소장권(9,900원)' 모의 결제를 지원합니다.
*   **다양한 결제 수단**: 신용/체크카드, 카카오페이, 토스페이, 네이버페이 등 국내의 대표적인 간편 결제 수단을 제공합니다.
*   **현실적인 결제 애니메이션**: 로딩 스피너 및 3단계 승인 진행 메시지("세션 연결 중...", "승인 요청 중...", "처리 중...")를 제공하여 실제 전자금융 결제가 이루어지는 것과 같은 몰입감을 제공합니다.
*   **영구 보존**: 결제 상태 정보(`reflectai_is_paid`)가 로컬 스토리지에 저장되어 브라우저를 닫아도 결제 상태가 안전하게 유지됩니다.

### 3. 📊 프리미엄 감정 리포트 대시보드 (Premium Analytics)
기존의 감정 변화 선 그래프(Chart.js) 외에 프리미엄 결제 완료 시 다음과 같은 심층 데이터 분석 대시보드가 즉시 활성화됩니다:
*   **나의 감정 기상도 (Emotion Weather)**: 기록된 감정 지수(최소 -3에서 최대 +3)의 평균값을 계산하여 4가지 날씨 상태(쾌청 ☀️, 대체로 평온함 ⛅, 다소 흐림 ☁️, 비 또는 천둥 🌧️)로 표현하며 맞춤형 상태 분석을 제공합니다.
*   **이모지별 누적 비율 통계**: 6가지 감정 이모지(행복함 😍, 만족함 😊, 보통 😐, 피곤함 😴, 슬픔 😢, 화남 😡)가 기록된 횟수와 백분율 통계를 예쁘게 시각화하여 보여줍니다.
*   **요일별 감정 지수 차트**: 월요일부터 일요일까지 요일별 평균 감정을 가로 막대바 차트로 시각화하며, 데이터 분석을 바탕으로 "가장 기분이 좋은 요일"과 "피로가 누적된 요일"을 자동으로 찾아 유용한 인사이트를 제공합니다.
*   **AI 마음 건강 조언 (AI Care Letter)**: 사용자의 감정 성향과 일기 기록을 다각도로 분석하여 사용자의 이름(Google 로그인 닉네임)을 부르며 다정하게 건네는 구체적인 힐링 조언 레터를 생성합니다.

### 4. 📝 감정 기록 및 캘린더 (Mood Tracking & Calendar)
*   **직관적인 캘린더 UI**: 어떤 날 감정 기록을 남겼는지 일별로 이중 표시(점 및 배경색 하이라이트)하여 파악하기 쉽습니다.
*   **성찰 질문 (Daily Reflections)**: 매일 질문 풀에서 무작위로 선택된 2가지 질문(예: *"오늘 가장 기억에 남는 순간은?"*, *"오늘 감사함을 느꼈던 일은?"*)이 제시되어 일기 작성을 돕습니다.
*   **실시간 AI 격려 피드백**: 기록한 일기의 분량(30자 기준)에 따라 실시간으로 격려와 응원의 피드백 메시지가 표시됩니다.
*   **스트릭 뱃지 (Streak)**: 연속으로 일기를 기록한 누적 일수를 홈 화면에 불꽃 아이콘과 함께 표시하여 동기를 부여합니다.

## 🎨 디자인 시스템 (SEED Design System)

전문적인 토스 SEED 디자인 시스템 규격을 적용하여, 일관되고 반응성이 좋은 미려한 인터페이스를 구축하였습니다.

*   **Color Palette (Pink Theme)**: 부드럽고 따뜻한 감성의 핑크 테마 컬러(`#ff8ecf`)를 메인 브랜드 색상으로 정의하고 다채로운 톤온톤 파스텔 색상을 조화롭게 배치했습니다.
*   **Typography**: 가독성과 현대성을 극대화한 `Pretendard` 서체를 적용했습니다.
*   **Components & Spacing**: 버튼 크기(Large 52px, Medium 44px), 모서리 반경(Radius r2/r3/r4/full), 그림자(shadow-s3) 등을 SEED 규칙에 따라 일관되게 설계했습니다.
*   **Micro-animations**: 화면 진입 시의 부드러운 페이드업, 결제창의 슬라이드업, 버튼 마우스 오버 시 미세한 축소 및 부드러운 트랜지션 효과(`cubic-bezier`)를 더해 한층 고급스럽고 역동적인 사용자 경험을 선사합니다.

## 🛠️ 기술 스택 (Tech Stack)

*   **HTML5 / CSS3 / Vanilla JavaScript** (단일 파일 독립 실행 가능)
*   **Google Identity Services SDK** (구글 One Tap / Sign-In 연동)
*   **Chart.js** (최근 감정 흐름 시각화)
*   **Google Material Symbols Rounded** (통일감 있는 둥근 모서리 아이콘)
*   **Pretendard** (고화질 한국어 웹 폰트)
*   **Local Storage**: 데이터베이스 서버 없이도 모든 로그인 상태, 결제 상태, 감정 기록 데이터가 브라우저에 안전하게 영구 저장됩니다.

## 🚀 실행 및 테스트 방법 (How to Run & Test)

이 프로젝트는 서버 구축이 필요 없는 단일 HTML 파일(`최종.html`)로 개발되었습니다.

1.  `최종.html` 파일을 로컬 컴퓨터로 다운로드합니다.
2.  Chrome, Safari, Edge 등 현대적인 웹 브라우저에서 `최종.html`을 더블 클릭하여 실행합니다. (모바일 기기 해상도에 최적화되어 있으므로, PC 브라우저 개발자 도구(`F12`)의 모바일 디바이스 뷰어 모드로 확인 시 더욱 자연스러운 UI를 즐기실 수 있습니다.)
3.  **구글 로그인 및 시뮬레이션**:
    *   우측 상단 프로필 영역(`account_circle`)을 누릅니다.
    *   실제 Client ID가 있는 경우 입력 후 실제 로그인을 시도할 수 있으며, 없더라도 **[구글 로그인 시뮬레이터 실행]** 버튼을 통해 가상으로 로그인 완료 상태를 구현하여 프로필 사진과 계정 메일이 반영되는 모습을 확인하실 수 있습니다.
4.  **기록 저장 및 프리미엄 테스트**:
    *   [오늘의 기록 쓰기]에서 캘린더 날짜를 선택하고 질문 작성 및 감정을 선택해 [기록 저장하기]를 수행합니다.
    *   [감정 분석 보기] -> [프리미엄 리포트] 탭으로 이동하여 [리포트 활성화] 버튼을 누른 후 모의 결제 플로우를 완료하면 차트와 날씨, 요일별 통계 및 AI 조언이 연동되는 프리미엄 화면을 체험하실 수 있습니다.
5.  **테스트 데이터 초기화**:
    *   테스트를 처음부터 다시 진행하려는 경우, 프로필 모달 하단의 **[데이터 및 결제 전체 리셋]** 버튼을 클릭하여 모든 기록과 정보를 깨끗하게 비울 수 있습니다.
