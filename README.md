# 🌸 ReflectAI (Pink Edition)

ReflectAI는 SEED 디자인 시스템(Pink 테마)을 적용하여 새롭게 단장한 모바일 친화적 웹 애플리케이션입니다. 매일의 감정을 기록하고, 하루를 돌아보는 질문에 답하며 스스로의 마음을 다독일 수 있도록 도와줍니다.

## ✨ 주요 기능 (Key Features)

*   **감정 기록 및 캘린더 (Mood Tracking & Calendar)**
    *   날짜별로 자신의 감정과 일기를 기록할 수 있습니다.
    *   직관적인 캘린더 UI를 통해 어떤 날 기록을 남겼는지 한눈에 파악할 수 있습니다.
    *   감정을 6가지 이모지(😍, 😊, 😐, 😴, 😢, 😡)로 선택하여 기록합니다.
*   **자기 성찰을 돕는 질문 (Daily Reflections)**
    *   매일 무작위로 주어지는 성찰 질문(예: "오늘 가장 기억에 남는 순간은 언제였나요?", "오늘 감사함을 느꼈던 일이 있나요?")에 답하며 하루를 의미 있게 마무리지을 수 있습니다.
*   **감정 분석 그래프 (Emotion Analysis Chart)**
    *   `Chart.js`를 활용하여 기록된 감정 점수 변화를 시각적인 선 그래프로 보여줍니다.
    *   내 감정의 흐름을 파악하고 스스로의 상태를 모니터링할 수 있습니다.
*   **스트릭(연속 기록) 및 피드백 (Streak & AI Feedback)**
    *   얼마나 꾸준히 기록했는지 보여주는 누적 기록(Streak) 뱃지가 제공되어 동기를 부여합니다.
    *   기록의 상세함에 따라 따뜻한 격려의 피드백 메시지가 나타납니다.
*   **첫 사용자 튜토리얼 (Tutorial Dialog)**
    *   처음 방문하는 사용자를 위해 앱의 핵심 기능을 소개하는 친절한 튜토리얼 모달이 제공됩니다.

## 🎨 디자인 시스템 (SEED Design System)

전문적인 SEED 디자인 시스템의 토큰을 차용하여 일관되고 아름다운 UI/UX를 구축했습니다.

*   **Color Palette (Pink Theme):** 부드럽고 따뜻한 느낌을 주는 핑크 계열의 색상(`--seed-bg-brand-solid: #ff8ecf`)을 주조색으로 사용했습니다.
*   **Typography:** 가독성이 뛰어나고 현대적인 `Pretendard` 폰트를 적용했습니다.
*   **Components & Spacing:** 버튼, 그림자, 모서리 곡률(Radius) 등에 SEED 시스템의 규칙을 적용하여 통일성 있는 인터페이스를 제공합니다.
*   **Micro-animations:** 화면 전환, 버튼 호버, 팝업 등장 등에 부드러운 애니메이션 곡선(`cubic-bezier`)을 적용하여 생동감 있는 사용자 경험을 선사합니다.

## 🛠️ 기술 스택 (Tech Stack)

*   **HTML5 / CSS3 / Vanilla JavaScript**
*   **Chart.js** (감정 분석 데이터 시각화)
*   **Google Material Symbols** (아이콘)
*   **Pretendard** (웹 폰트)
*   **Local Storage**: 브라우저 로컬 스토리지를 활용하여 별도의 서버 없이도 사용자의 기록을 안전하게 기기에 저장합니다.

## 🚀 실행 방법 (How to Run)

본 프로젝트는 프론트엔드 단일 파일(`최종.html`)로 구성되어 있어 별도의 설치 과정이 필요하지 않습니다.

1.  `최종.html` 파일을 다운로드합니다.
2.  Chrome, Safari, Edge 등 현대적인 웹 브라우저에서 `최종.html` 파일을 더블 클릭하여 엽니다. (모바일 뷰어 또는 브라우저의 개발자 도구 - 모바일 화면 모드에서 보면 더욱 최적화된 UI를 경험할 수 있습니다.)
3.  브라우저 내에서 자유롭게 감정을 기록하고 기능을 테스트해 보세요!
